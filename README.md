# AI-flight-Assistant
Ingested daily flight data as embeddings. Users ask natural-language questions (e.g. 'next flight to London') and the LLM interprets the query, matches it against the source, and returns precise results (flight number, gate, etc.), visualized through a 3D flight-path web GIS application.
